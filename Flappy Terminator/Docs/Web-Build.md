# Веб-версия для тестеров

## Собрать

1. В Unity: **Tools → Build → Web**.
2. Номер версии поднимается сам (0.1.0 → 0.1.1 → …) и виден в правом нижнем углу стартового
   экрана — тестеры называют его в отчётах.
3. Сборка ложится в `Builds/Web/v<версия>/` (папка `Builds/` не в git). Первая сборка идёт
   5–15 минут, следующие быстрее.

Настройки, которые выставляет скрипт (`Assets/Editor/Publish/WebBuild.cs`, отдельно —
**Tools → Build → Apply Web Settings**):

| Настройка | Значение | Зачем |
|---|---|---|
| Сжатие | Gzip + Decompression Fallback | открывается на любом хостинге без настройки сервера |
| Name Files As Hashes | вкл | у новой сборки новые имена файлов — браузер не подсунет старую версию из кэша |
| Размер окна | 1280 × 720 | под него свёрстан интерфейс |
| Data Caching | вкл | повторный запуск той же версии грузится из кэша браузера |
| Шаблон страницы | `Assets/WebGLTemplates/Flappy Full Window` | игра на всё окно браузера любого размера, тёмный фон, полоса загрузки, версия в заголовке вкладки |

Фон космоса растягивается под соотношение сторон кадра (`BackgroundFit`): на вытянутых
экранах телефонов по краям больше нет тёмных полос.

Интерфейс масштабируется под размер окна (Canvas Scaler: Scale With Screen Size, эталон
1280 × 720, баланс ширины и высоты 0.5). Проверено на 1280 × 720, 4 : 3, 16 : 10 и
19.5 : 9 (телефон в горизонтали).

Перед первой сборкой понадобилось:

- **Перезапустить Unity после установки Web Build Support.** Редактор, запущенный до
  установки модуля, «успешно» собирает только данные, а на шаге упаковки пишет в отчёт
  «Build target 'WebGL' not supported» — папка сборки не появляется.
- **Выключить URP Compatibility Mode** (переход на Render Graph). Unity 6.3 не собирает проект
  с этим устаревшим режимом. Своих render feature в проекте нет, картинка в игре не изменилась.
- Папка скрипта называется `Publish`, а не `Build`: корневой `.gitignore` репозитория прячет
  все папки `Build/`. Файлы `Assets/Resources/PerformanceTestRun*`, которые пакет тестов
  производительности пишет при каждой сборке, добавлены в `.gitignore` проекта.

## Выложить

1. Загрузить **содержимое** папки `Builds/Web/v<версия>/` (`index.html`, `Build/`,
   `TemplateData/`) в отдельный каталог сайта, например `вашсайт/flappy/`.
2. Сайт должен открываться по **https** — по http многие браузеры не запускают такие игры.
3. Ссылка для тестеров — `https://вашсайт/flappy/`.

Проверить сборку локально до выкладки: открыть `index.html` двойным кликом нельзя (браузер
блокирует загрузку файлов с диска). Нужен любой локальный сервер, например в терминале:
`python3 -m http.server 8000` в папке сборки и адрес `http://localhost:8000`.

## Обновить

1. **Tools → Build → Web** — появится `Builds/Web/v<новая версия>/`.
2. На сайте **удалить старое содержимое** каталога и загрузить новое целиком. Остатки старых
   файлов не мешают (у новых другие имена), но занимают место.
3. Сообщить тестерам номер версии. Если кто-то видит старую — обновить страницу
   (Cmd+Shift+R / Ctrl+F5).

Хотите хранить старые версии — выкладывайте каждую в свой каталог (`flappy/v0.1.1/`,
`flappy/v0.1.2/`), а тестерам давайте ссылку на последнюю.

## Проверено

Сборки v0.1.1–v0.1.3 открыты в браузере с локального сервера: загрузка, стартовое меню,
START TEST → ангар 1m / 1m, покупка, PLAY → бой, управление с клавиатуры. Окна 1440 × 900,
900 × 560 и телефон 812 × 375 — игра на всё окно, номер версии вверху по центру. При
пересборке без изменений кода (v0.1.2) новое имя получил только файл данных — браузеры
тестеров не перекачивают движок.

## Если хостинг неудобен

itch.io принимает ту же папку в zip («Kind of project: HTML»), сам отдаёт сжатые файлы,
может закрыть страницу паролем («Restricted» + password). Обновление — загрузить новый zip.

## Известные особенности веб-версии

- Звук включается после первого клика или касания — так требуют браузеры.
- Клавиатура работает, когда игра в фокусе: по ней нужно один раз кликнуть.
- Прогресс между запусками не сохраняется — так задумано (прокачка живёт одну сессию).
