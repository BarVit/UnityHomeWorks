# ТЗ-05. Оружие

[← План развития](Roadmap.md) · раздел 7.1

**Вид работы:** боевые системы
**Зависит от:** ТЗ-01, ТЗ-02
**Блокирует:** ТЗ-06, ТЗ-07, ТЗ-12

## Цель

Шесть стволов демо с ростом до четырёх дул каждый. Ключевое: это **пять разных механик
доставки урона**, а не шесть наборов чисел над одним снарядом.

## Текущее состояние

`PlayerShooter` — одна точка `_shootPoint`, один префаб `Ammo`, кулдаун `_shootRate`,
корутина `Reload`, событие `ReadinessChanged` наружу.
`EnemyShooter` — свой цикл стрельбы, с проверкой `ScreenArea.Contains` перед звуком.
`Ammo` — один класс: `BulletMover`, урон, эффект попадания, звук.

Пул создаётся в `Awake` под конкретный префаб. При шести пушках со своими снарядами
и эффектами это не масштабируется.

## Механики доставки урона

| Механика | Оружие | Что требуется |
|---|---|---|
| Снаряд | плазма, ракетница | есть сейчас |
| Снаряд с наведением | самонаводящаяся ракетница | выбор цели, доворот |
| Мгновенный луч | рельсотрон | попадание без снаряда, отрисовка следа |
| Луч с перегревом | лазер | шкала нагрева вместо кулдауна, непрерывный урон |
| Постоянный снаряд с уроном по времени | плазменный шар | зона урона с тиками, не исчезает при попадании |

## Точки крепления и схемы залпа

Точки крепления — массив `Transform` на корабле; сколько активно, задаёт апгрейд.

| Оружие | Апгрейд до 4 |
|---|---|
| Плазма | 4 выстрела конусом |
| Ракетница | 2 вперёд, 2 в стороны |
| Самонаводящаяся | 4 ствола параллельно |
| Лазер | число стволов |
| Рельсотрон | 2 вперёд, 2 в стороны узким конусом |
| Плазменный шар | не стволы, а размер и кулдаун |

## Реестр пулов

Пулы перестают создаваться под конкретный префаб в `Awake`. Нужен реестр, выдающий
`SpawnPool<T>` по префабу и переиспользующий уже созданный.

## Данные

`weapons.tsv`: `id`, `delivery` (механика), `damage`, `rate`, `projectile_speed`,
`barrels_max`, `fire_pattern`, `heat_per_shot`, `cooldown_rate`, `price`, префаб снаряда,
префаб эффекта, звук.

Различия внутри механики — параметры. Сами механики — код, по одной реализации на строку.

## Не входит

- UI перегрева и слотов — ТЗ-12. Здесь только событие наружу.
- Оружие врагов — ТЗ-06 переиспользует готовое.
- Модули — ТЗ-08.
- Условие открытия плазменного шара за босса — ТЗ-07.

## Критерий готовности

1. Все шесть пушек стреляют и наносят урон.
2. Апгрейд до 4 дул меняет схему залпа согласно таблице.
3. Лазер стреляет без кулдауна, перегревается, перестаёт стрелять, остывает.
4. Рельсотрон бьёт мгновенно на всю ширину экрана.
5. Плазменный шар не исчезает при попадании и наносит урон, пока цель его касается.
6. Все характеристики читаются из `weapons.tsv`.

## Известные ловушки

- **`OnTriggerStay2D` доставляется и выключенным компонентам.** Плазменный шар считает урон
  именно так — эту ловушку в проекте уже ловили на другом коде.
- **Цель самонаведения может уйти в пул в том же кадре.** Проверять не `== null`, а живость
  через состояние пула: у уничтоженного `UnityEngine.Object` перегруженный оператор сравнения
  ведёт себя не так, как ожидает `?.`.
- **Рельсотрон не создаёт снаряд** — попадание через `Physics2D`, мимо пула. Следствие: эффект
  попадания и звук идут по другому пути, чем у остальных пушек.
- **Урон по времени и `IDamageable.TakeDamage(int)`.** Тик урона должен быть целым и не
  вырождаться в ноль на слабых значениях.
- **Звук вне экрана.** `EnemyShooter` уже проверяет `ScreenArea.Contains` перед
  воспроизведением — новые механики должны делать то же, иначе вернётся баг со стрельбой
  из-за кадра.
- **Громкость едет вместе с клипом** в структуре `Sound`. Не собирать новые источники звука
  копированием чужих настроек: так уже получался выстрел в шесть раз громче нужного.
