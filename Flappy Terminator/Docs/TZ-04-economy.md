# ТЗ-04. Экономика и сохранение

[← План развития](Roadmap.md) · раздел 4, 7

**Вид работы:** игровая логика
**Зависит от:** ТЗ-03
**Блокирует:** ТЗ-08, ТЗ-09, ТЗ-10

## Цель

Замкнуть петлю: забег даёт награду, награда сохраняется между запусками, тратить её можно
между локациями.

## Три шкалы

| Шкала | Начисляется | Область действия |
|---|---|---|
| Опыт пилота | За убийства и прохождение | Все корабли |
| Опыт корабля | То же | Только этот корабль |
| Деньги | То же | Всё |

Опыт корабля нужен и при единственном корабле в демо: он даёт вторую линию прогресса
на те четыре часа, где покупать новый корабль негде.

## Что сохраняется

| Класс | Содержимое |
|---|---|
| `PlayerProfile` | Уровень и опыт пилота, выученные скиллы, деньги |
| `ShipProgress` | Опыт корабля, установленные пушки и модули |
| `GalaxyProgress` | Пройденные системы и локации |
| `RunState` | **Не сохраняется** — живёт только внутри забега |

Формат — JSON в `Application.persistentDataPath`. Поле версии формата в файле обязательно:
структура сохранения будет меняться каждым следующим ТЗ.

## Момент сохранения

**Между локациями, и только там.** Не по таймеру и не на каждое убийство: точка сохранения —
часть правил игры, а не техническая деталь. Сохранение внутри локации сделало бы возможным
обход правила «за один заход».

## Данные

`progression.tsv` — кривые опыта и награды:

| Столбец | Смысл |
|---|---|
| `id` | ключ строки |
| `pilot_level` | уровень пилота |
| `pilot_xp_required` | опыта до следующего уровня |
| `ship_xp_required` | то же для корабля |
| `kill_xp` | опыт за убийство |
| `kill_money` | деньги за убийство |
| `level_bonus` | множитель за пройденный уровень |

## Не входит

- Экран траты — ТЗ-10.
- Модули и скиллы, на которые тратят — ТЗ-08, ТЗ-09.
- Покупка кораблей: в демо корабль один.

## Критерий готовности

1. Убийства и прохождение уровня начисляют опыт пилота, опыт корабля и деньги.
2. Перезапуск игры — накопленное на месте.
3. Смерть посреди локации — начислено только за пройденные уровни.
4. Набор нужного опыта повышает уровень пилота и уровень корабля независимо друг от друга.
5. Все числа читаются из `progression.tsv`.

## Известные ловушки

- **Повторный заход оплачивается заново.** Погибнув на четвёртом уровне и начав локацию
  с первого, игрок снова получит награду за первые три. Это осознанное решение, а не дыра:
  гринд возможен, но требует честно проходить уровни. Не «чинить».
- **Версия формата.** Сохранение, записанное сегодняшним кодом, должно читаться завтрашним
  или осознанно отбрасываться. Без поля версии это выяснится на плей-тестах.
- **`persistentDataPath` переживает переустановку игры.** При отладке нужен способ сбросить
  профиль, иначе баланс будет проверяться на профиле недельной давности.
